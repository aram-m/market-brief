# Reporting rules (Solana and Robinhood)

These rules carry over the crypto-screener reporting agreement (`docs/dex-chat-reporting.md`, `docs/market-commands.md`), plus the decisions of 16 October 2026. Changing a filter, budget or exclusion requires an explicit request from the user.

## Discovery

- Load only the configured Dexscreener discovery page for each requested scope (`references/config.json`):
  - Solana: `https://dexscreener.com/solana?rankBy=trendingScoreH6&order=desc&minMarketCap=1000000&minAge=72&min24HVol=1000000&profile=1`
  - Robinhood: `https://dexscreener.com/robinhood?rankBy=trendingScoreH6&order=desc&minMarketCap=1000000&minAge=72&min24HVol=1000000&profile=1`
- Trial filters, kept until the user changes them: Trending 6H ranking, reported market cap ≥ $1M, pool age ≥ 72 h, pool 24h volume ≥ $1M, profile enabled.
- Discovery uses a real browser, because the page is behind a Cloudflare challenge for plain HTTP. Never solve, bypass or work around a challenge. If one is shown, that scope's run stops with `discovery blocked`.
- Record what was loaded: the exact URL, page title, filter indicator, observation time, rank-ordered pool slugs and a checksum.
- Discovery older than `discoveryMaxAgeMinutes` (60) is never reused; reload the page instead.

## Identity and aggregation

- A token is chain + contract. Solana mints keep their case; EVM addresses are compared lowercase. Discovery slugs are lowercase and are matched to the API's canonical pair address case-insensitively.
- Deduplicate identical pools, then sum 24h volume and liquidity across the token's distinct qualifying pools. If some pools lack a value, show the partial sum labelled `n/m pools` and sort by it.
- Price, 24h change, market cap and FDV come from the most liquid returned pool. Use FDV, labelled, only when market cap is missing. Valuation conflicts are measured facts: market cap above FDV, FDV spread across pools, and a 24h change spread of 10 points or more.
- A pool counts for its base token only. When the quote token is also a candidate, its record lists the pool under `alsoQuotedIn`, which is not added to its totals.
- Stablecoins, wrapped and native assets, and liquid-staking SOL are excluded as base tokens by exact contract (`references/excluded-base-assets.json`). Pools quoted in them are kept. A lookalike symbol that isn't on the list is flagged, not hidden.
- Display exclusions are exact ids in `<data>/preferences.json`. Hidden rows stay in observations with `hidden: true`.
- Filters are re-checked at metric time and failures recorded, but never applied. Differences between scans reflect the discovery page only, not chain-wide flows, launches or delistings.

## Request budget (per run)

| Read | Limit |
| --- | --- |
| Discovery page loads | 1 per scope, plus a 2nd page only if the first shows 100 rows and a next page |
| Dexscreener pair API | ≤ 30 addresses per call, one call at a time, ≤ 10 calls per run, ≤ 2 retries on 429/5xx/timeout |
| Project pages | ≤ 3 per project (main site, docs, GitHub) plus 1 listed X account |
| Chain reads | 1 batched Solana RPC call; 1 Robinhood stock-token registry read |
| Web search | ≤ 1 per row that is still incomplete after the page reads |

`budget.json` in each run records what was used.

## Delivery

- Show every eligible, non-hidden token, sorted by 24h volume descending with missing values last, in pages of 12. Token names link to the row's Dexscreener pair.
- First show the market table (marked "research pending"), then the final table with notes.
- Show the actual discovery and market-data times in Asia/Yerevan. Put material labels next to the affected metric or at the top: unresolved pools, failed requests, blocked discovery.
- Keep three kinds of content apart:
  - Measured facts, generated by the scripts.
  - Project claims, quoted with their source and never marked verified unless a measurement supports them.
  - AI interpretation, labelled as such.
- Mark unavailable evidence explicitly. If research fails, keep the market rows and name the missing source.
- Never present an earlier scan as current. If a scope fails, show what failed instead of older data.
- Leave methodology and full coverage in the saved report, not in the chat brief. End with the one-line disclaimer.
- Never place trades.
